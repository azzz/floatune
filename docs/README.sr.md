# Floatune

Мали прозор за управљање Spotify-јем на macOS-у. Стоји изнад свих прозора, појављује се и сакрива пречицом са тастатуре, а када га не дирате, постаје полупровидан.

У прозору су омот, назив песме и извођач, дугмад „претходна”, „пауза” и „следећа”, јачина звука у Spotify-ју и трака напретка коју можете превући да премотате.

## Захтеви

- macOS 14 или новији
- Десктоп апликација Spotify. Premium није потребан.

## Инсталација

Преузмите `Floatune-*.zip` из [најновијег издања](https://github.com/azzz/floatune/releases/latest), распакујте га и преместите `Floatune.app` у „Апликације”.

Апликација има ad-hoc потпис, а не Developer ID, па macOS блокира прво покретање. Уклоните ознаку карантина:

```
xattr -dr com.apple.quarantine /Applications/Floatune.app
```

Или покушајте да отворите апликацију, па кликните „Ипак отвори” у Системским подешавањима → Приватност и безбедност.

При првом покретању macOS пита да ли Floatune сме да управља Spotify-јем. Дозволите. После ажурирања macOS може поново да пита, јер свака верзија има свој ad-hoc потпис.

## Коришћење

| Радња | Како |
|---|---|
| Прикажи или сакриј прозор | ⌃⌥⌘S |
| Врати затамњеном прозору пуну непрозирност | Пређите мишем преко њега или притисните пречицу |
| Помери прозор | Превуците га за било које место. Положај се памти |
| Подешавања и излаз | Десни клик на прозор |

У подешавањима се мењају пречица, кашњење пре затамњења (1–15 s), непрозирност затамњеног прозора (10–90%), покретање при пријављивању и језик интерфејса. Измене важе одмах, осим језика, који захтева поновно покретање.

Клик на прозор не одузима фокус апликацији у којој радите.

## Како ради

Floatune комуницира са десктоп Spotify-јем преко Apple Events, истим командама које користи AppleScript. Spotify сам јавља промену песме системским обавештењем `com.spotify.client.PlaybackStateChanged`, па ништа не проверава стање у позадини. Floatune не користи Spotify Web API и иде на интернет само по омоте.

Ограничења:

- Нема реда следећих песама. Даје га само Web API, а он захтева OAuth и налог програмера.
- Клизач мења јачину звука самог Spotify-ја, а не системску.
- Spotify не шаље обавештење при премотавању. Док је прозор видљив и песма свира, Floatune поново чита позицију на сваких 5 секунди.
- Ако је Spotify затворен, Floatune га не покреће и нуди дугме да га отворите.

## Језици

Floatune је преведен на енглески, руски, украјински, српски (ћирилица), хрватски и румунски и прати језик система. Да изаберете други, кликните десним тастером на прозор → „Подешавања…” → „Језик”, па кликните „Поново покрени”.

### Додавање језика

1. Копирајте `Resources/en.lproj` у `Resources/<код>.lproj`, где је `<код>` код језика: `de`, `pl`, `pt-BR`.
2. Преведите вредности у `Localizable.strings` и `InfoPlist.strings`. Кључеве на левој страни не мењајте и задржите сваки `%@`.
3. Покрените `python3 scripts/check_strings.py`. Скрипта пада ако неки кључ недостаје или је вишак, или ако превод промени `%@`.
4. Изградите апликацију. Нови језик се сам појављује у „Подешавањима” → „Језик”; изаберите га и проверите сваки екран.

## Изградња из изворног кода

Довољни су Command Line Tools, Xcode није потребан.

```
./scripts/build.sh
open build/Floatune.app
```

Скрипта чита ове променљиве окружења:

| Променљива | Шта задаје | Подразумевано |
|---|---|---|
| `ARCHS` | Архитектуре одвојене размаком, нпр. `"arm64 x86_64"` | Архитектура вашег Mac-а |
| `VERSION` | `CFBundleShortVersionString` | Вредност из `Resources/Info.plist` |
| `BUILD_NUMBER` | `CFBundleVersion` | Вредност из `Resources/Info.plist` |
| `SIGN_ID` | Сертификат за потписивање | Ad-hoc потпис |

Gatekeeper не проверава апликацију коју сте изградили локално: macOS ставља ознаку карантина само на преузете фајлове.

## Издања

CI проверава преводе и гради universal апликацију при сваком push-у у `main` и за сваки pull request. Да објавите издање, пушујте таг:

```
git tag v0.2.0
git push origin v0.2.0
```

Workflow гради апликацију са верзијом из тага и објављује GitHub Release са zip архивом.
