# Floatune

Маленьке вікно для керування Spotify на macOS. Висить поверх усіх вікон, з'являється і ховається за гарячою клавішею, а коли його не чіпають, стає напівпрозорим.

У вікні: обкладинка, назва треку й виконавець, кнопки «назад», «пауза» і «вперед», гучність Spotify і смуга прогресу, яку можна тягнути для перемотування.

## Вимоги

- macOS 14 або новіша
- Десктопний Spotify. Premium не потрібен.

## Встановлення

Завантажте `Floatune-*.zip` з [останнього релізу](https://github.com/azzz/floatune/releases/latest), розпакуйте й перенесіть `Floatune.app` у «Програми».

Застосунок підписано ad-hoc, без Developer ID, тому під час першого запуску macOS його заблокує. Зніміть карантин:

```
xattr -dr com.apple.quarantine /Applications/Floatune.app
```

Або спробуйте відкрити застосунок, а потім натисніть «Усе одно відкрити» в Системних параметрах → Приватність і безпека.

Під час першого запуску macOS запитає, чи може Floatune керувати Spotify. Дозвольте. Після оновлення питання може повторитися: у кожної збірки свій ad-hoc підпис.

## Як користуватися

| Дія | Як |
|---|---|
| Показати або сховати вікно | ⌃⌥⌘S |
| Повернути потьмянілому вікну непрозорість | Навести курсор або натиснути гарячу клавішу |
| Перемістити вікно | Перетягнути за будь-яке місце. Позиція зберігається |
| Параметри й вихід | Правий клік по вікну |

У параметрах змінюються гаряча клавіша, затримка перед потьмянінням (1–15 с), непрозорість потьмянілого вікна (10–90%), автозапуск під час входу й мова інтерфейсу. Зміни застосовуються одразу, крім мови: вона потребує перезапуску.

## Як це працює

Floatune спілкується з десктопним Spotify через Apple Events, тими самими командами, що доступні з AppleScript. Про зміну треку Spotify повідомляє сам, через системне сповіщення `com.spotify.client.PlaybackStateChanged`, тому опитування у фоні немає. Spotify Web API не використовується. У мережу застосунок ходить лише по обкладинки.

Обмеження:

- Черги наступних треків немає. Її віддає тільки Web API, а він вимагає OAuth і акаунт розробника.
- Слайдер змінює гучність самого Spotify, а не системну.
- Spotify не надсилає сповіщення під час перемотування. Поки вікно видно і трек грає, Floatune перечитує позицію раз на 5 секунд.
- Якщо Spotify закрито, Floatune його не запускає і пропонує відкрити кнопкою.

## Мови

Floatune перекладено англійською, російською, українською, сербською (кирилиця), хорватською та румунською, і він стежить за мовою системи. Щоб вибрати іншу, клацніть правою кнопкою по вікну → «Параметри…» → «Мова» і натисніть «Перезапустити».

### Як додати мову

1. Скопіюйте `Resources/en.lproj` у `Resources/<код>.lproj`, де `<код>` — код мови: `de`, `pl`, `pt-BR`.
2. Перекладіть значення в `Localizable.strings` і `InfoPlist.strings`. Ключі зліва не чіпайте й збережіть кожен плейсхолдер `%@`.
3. Запустіть `python3 scripts/check_strings.py`. Скрипт впаде, якщо ключа бракує, є зайвий або переклад змінив плейсхолдери.
4. Зберіть застосунок. Нова мова сама з'явиться в «Параметрах» → «Мова»; виберіть її й перевірте всі екрани.

## Збирання з вихідного коду

Вистачить Command Line Tools, Xcode не потрібен.

```
./scripts/build.sh
open build/Floatune.app
```

Скрипт читає змінні оточення:

| Змінна | Що задає | За замовчуванням |
|---|---|---|
| `ARCHS` | Архітектури через пробіл, наприклад `"arm64 x86_64"` | Архітектура вашого Mac |
| `VERSION` | `CFBundleShortVersionString` | Значення з `Resources/Info.plist` |
| `BUILD_NUMBER` | `CFBundleVersion` | Значення з `Resources/Info.plist` |
| `SIGN_ID` | Сертифікат для підпису | Ad-hoc підпис |

Локально зібраний застосунок Gatekeeper не перевіряє: карантин ставиться лише на завантажені файли.
